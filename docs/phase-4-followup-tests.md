## Not Covered

The following capabilities were intentionally excluded or remain pending further environment setup:

1. **Live OSRM Container Execution:**
   The OSRM routing provider is verified against a local mock HTTP server and unit tests with mocked fetch. Verification against an active `osrm-routed` Docker container remains pending because Docker Desktop daemon was unavailable in this evaluation environment, and no sub-national Delhi PBF extract was available without live clipping.
2. **Persistent Hazard Zone Entity CRUD:**
   Hazard zones are currently accepted exclusively as request-scoped parameters (`blockedZones`) on `POST /assignments/propose`. There is no persistent database entity or dedicated CRUD API (`/zones`), which is deferred to future operational operational phases.
3. **Empirical Telemetry Calibration of Uncertainty Parameters:**
   The coefficients for base variance, water surge, caution impedance, water depth, and weather in `calculateCoefficientOfVariation` and `RiskAwareTravelTimeProvider` are heuristic placeholders (`// placeholder, not measured`) and have not been calibrated against real-world GPS telemetry from active flood rescue missions.
